# 05.06 ADR-0003: SAKAAI Alignment, ULID Primary Key Adoption, & Larastan Level 7 Quality Gate

## Context

Proyek Laravel 13 starter kit memerlukan penataan arsitektur yang konsisten dan patuh 100% terhadap arsitektur SAKAAI DDD-Lite Modular. Sebelumnya terdapat fragmentasi struktur entitas (seperti Model `User` di root `app/Models/`), ketiadaan penegakan `strict_types`, controller dengan metode berukuran besar, primary key berbasis auto-increment integer, dan potensi error static analysis yang belum terverifikasi secara ketat.

## Decision

Telah disetujui dan diterapkan standar rekayasa perangkat lunak berikut:

1. **SAKAAI Single Source of Truth**:
   - Seluruh pekerjaan rekayasa perangkat lunak wajib tunduk pada pedoman SAKAAI (`GOV000`, `LAR001`, `SPC006`).
   - 25 SAKAAI Agent Skills diaktifkan secara otomatis via `.agents/skills.json`.

2. **Refactoring DDD-Lite & Strict Discipline**:
   - `declare(strict_types=1);` diterapkan di 100% (100/100) berkas PHP pada direktori `app/`.
   - Entitas Eloquent `User` dipindahkan dari `app/Models/User.php` ke `App\Modules\Console\UserManagement\Domain\Entities\User`.
   - Dibuat struktur folder `Domain/Entities/` dan `Domain/Events/` yang konsisten di 5 modul platform (`UserManagement`, `AccessControl`, `SystemSetting`, `AuditLog`, `Profile`).
   - Penegakan `final class` pada seluruh class Transaction, DTO, Event, dan Integration Service.
   - Refactoring Controller menjadi Slim Controllers (< 50 baris per class).

3. **ULID Primary Key Migration**:
   - Seluruh entitas domain utama (`User`, `SystemSetting`, `Passkey`, `Media`) menggunakan trait `HasUlids`.
   - Skema migrasi basis data diperbarui menggunakan `$table->ulid('id')->primary()`, `$table->ulid('user_id')`, `$table->foreignUlid('user_id')`, dan `$table->ulidMorphs('model')`.
   - Kontrak interface, DTO, Domain Event, dan Service disesuaikan untuk menerima tipe `int|string` demi kompatibilitas ULID string.

4. **Quality Gate & Automated Verification**:
   - **Static Analysis**: Larastan (PHPStan) Level 7 lulus 100% tanpa error (`0 errors`).
   - **Code Style**: Formatting disesuaikan secara otomatis menggunakan Laravel Pint (`vendor/bin/pint --parallel`).
   - **Test Suite**: 58 Unit & Feature Tests di bawah `tests/Feature/Modules/` lulus 100% (187 assertions).

## Consequences

### Positive
- Batas modul domain menjadi sangat tegas, bersih, dan mematuhi arsitektur DDD-Lite.
- Identifier ULID memberikan ketahanan terhadap enumerasi ID pada URL/API dan memudahkan sinkronisasi distributed system.
- Static analysis Level 7 menjamin ketiadaan bug tipe data, missing PHPDoc, atau unhandled null pointer pada runtime.
- Seluruh perbaikan otomatis terverifikasi oleh test suite Pest yang hijau (100% PASS).

### Negative / Trade-offs
- Refactoring namespace `User` memerlukan alias backward compatibility pada `app/Models/User.php` untuk paket pihak ketiga yang mengekspektasi class tersebut di lokasi default.
