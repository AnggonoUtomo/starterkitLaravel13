## Purpose and Scope

Event bus dispatches typed domain/integration events synchronously or through queue.

Events carry ULID correlation ID and sanitized payload. Listeners are isolated, retry-safe, and idempotent where side effects can repeat.

## Implementation Contract

- All identifiers and correlation data use ULID.
- Public output is typed, deterministic, and sanitized.
- Cross-module communication uses public contract, DTO, or typed event.
- Module invalid is isolated and valid modules continue running.
- Wayfinder and Laravel Boost are forbidden in dependencies and output.
- Secret, token, credential, password, and sensitive payload never enter logs,
  diagnostics, templates, cache, or generated files.
- Mutation requiring authorization produces audit evidence.

## Failure Behavior

Validation fails before side effect. Runtime failure returns stable error code,
actionable diagnostic, and safe fallback where defined. Retry is allowed only
for idempotent operations or operations protected by an idempotency key.

## Acceptance Criteria

- Contract and integration tests cover happy, negative, authorization, and failure paths.
- Namespace, dependency, ULID, correlation ID, and redaction checks pass.
- Output is reproducible and verifiable through console, health, or diagnostic command.
- Documentation, README, test evidence, and cross-reference are available.
- Relevant CI, security, build, and browser gates pass.

## Verification

Developer runs focused unit, feature, integration, and contract tests. QA verifies
acceptance and critical flow. DevOps verifies health, log, queue, cache, deployment,
backup, and rollback impact where relevant.
